# Local demo assets V1

This workspace contains only public-safe, offline presentation assets. It reads the surrounding sanitized submission package and does not access the private orchestration system, account data, browser state, or notification configuration.

## Recording in four steps

1. In Finder, double-click `Run-Handmade-Creator-Radar-Demo-v1.command`.
2. Start a 16:9 screen recording as the title card appears.
3. Let the 76-second automatic sequence complete; no typing is required.
4. Stop recording after `DEMO COMPLETE` remains on screen, then review once for unexpected notifications.

The entrypoint clears the terminal and replaces its title before displaying content. Keep the terminal full-screen and do not show Finder, browser, or account windows.

## Included output

- `output/handmade-creator-radar-cover-v1.png`: 1800×1200, English 3:2 cover, generated locally with no external image, account, or private input.

## Intentional fallback

No H.264 encoder was available among existing safe tools, so this workspace does not create an MP4. The double-click sequence is the approved local capture path; it requires no software installation or code changes to the frozen radar.
